1️⃣ Core Objective

Transform:

Static portfolio page

Into:

Evidence-backed capability signal system

Focus = signal quality, not decoration.

2️⃣ Signal Architecture (Minimal + Effective)
Layer 1 — Identity Signal (Hero Section)

Short, dense:

Role positioning (e.g., Backend SWE – Entry)

Primary stack

Deterministic scoring model (1-line formula)

Overall capability index badge

Purpose:
Immediate clarity within 5–7 seconds.

Layer 2 — Capability Matrix (Core Engine)

Matrix:

Capability × Level × Evidence → Score

Rules:

Use dynamic evidence computation (not static mapping)

Multiply level strength × strongest evidence weight

No GitHub vanity metrics

Purpose:
Structured credibility.

Layer 3 — Evidence Cards (Proof Units)

Each project:

Problem

Constraints

Design choice

Trade-off

Outcome

Short. No storytelling fluff.

Purpose:
Convert abstract capability → concrete engineering behavior.

Layer 4 — Optional Advanced Signals (Collapsed)

Expandable:

Active repositories

Last updated

Languages used

Gap areas (very strong trust signal)

Hide by default to reduce cognitive load.

4️⃣ What Is Optional vs Essential
Essential

Clean matrix

Dynamic evidence scoring

Clear positioning

Minimal cognitive load

Optional

5️⃣ What To Avoid

Over-dashboard appearance

Too many metrics

Autoplay media

Horizontal scrolling

Vanity GitHub numbers

Signal clarity > signal volume.

6️⃣ Final Strategic Position

Your system should communicate:

“This candidate reasons in structured, deterministic systems.”

Not:

“This candidate built many repos.”

That difference is large.

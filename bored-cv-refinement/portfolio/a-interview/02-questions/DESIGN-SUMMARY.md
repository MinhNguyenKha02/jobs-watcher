## 🎯 How to Use This System

### Day 1 (First Time Setup - 60 minutes)
1. Read [README.md](README.md) (15 min)
2. Read [QUICKSTART.md](QUICKSTART.md) Day 1 section (15 min)
3. Print/bookmark [QUICK-REFERENCE.md](QUICK-REFERENCE.md) (5 min)
4. Copy [daily-compression-template.md](daily-compression-template.md) to `daily-20260303.md`
5. Complete first practice session (30 min)

### Daily Practice (60-75 minutes)
1. Open [QUESTION-TRACKER.md](QUESTION-TRACKER.md) → Select question (2 min)
2. Copy template → `daily-YYYYMMDD.md` (1 min)
3. Complete practice session (60 min)
   - Framework Review (5 min)
   - Today's Focus (10 min)
   - Build/Respond (25 min) ← Core practice
   - Unpack Decisions (10 min)
   - Self-Assessment (5 min)
   - Learning Log (5 min)
4. Compare to example in [interview-preparation.md](interview-preparation.md) (10 min)
5. Score using [RESPONSE-EVALUATION-FRAMEWORK.md](RESPONSE-EVALUATION-FRAMEWORK.md) (5 min)
6. Update [QUESTION-TRACKER.md](QUESTION-TRACKER.md) with attempt (3 min)

### Weekly Review (30-45 minutes every Sunday)
1. Review all `daily-*.md` files from week (5 min)
2. Use [WORKFLOW.md](WORKFLOW.md) Weekly Review Checklist (20 min)
3. Update [QUESTION-TRACKER.md](QUESTION-TRACKER.md) Progress Dashboard (10 min)
4. Update [gaps.md](gaps.md) with progress notes (5 min)
5. Plan next week in QUESTION-TRACKER.md (5 min)

### When Stuck
1. Check [QUICK-REFERENCE.md](QUICK-REFERENCE.md) Decision Tree
2. Review [STRUCTURE.md](STRUCTURE.md) to see file connections
3. Go back to [README.md](README.md) for navigation

## 🎓 Key Design Decisions

### 1. Separation of Concerns
- **Navigation** files separate from **Strategy** files
- **Practice** tools separate from **Evaluation** tools
- Each file has ONE clear purpose

### 2. Progressive Disclosure
- **Quick Reference** → surface-level info, print and use
- **Structure** → mid-level, how things connect
- **System Design** → deep-level, complete understanding

### 3. Feedback Loops
- **Daily:** Practice → Self-Assess → Compare → Track
- **Weekly:** Review → Analyze → Reflect → Plan
- **Per Question:** Attempt 1 → Study → Attempt 2 → Study → Attempt 3 → Master

### 4. Multiple Entry Points
- **Beginner:** README → QUICKSTART → Daily Practice
- **Quick Start:** QUICK-REFERENCE → Daily Practice
- **System Understanding:** README → STRUCTURE → SYSTEM-DESIGN
- **Lost:** STRUCTURE → Decision Tree → Right File

### 5. Visual Learning Support
- ASCII diagrams in VISUAL-FLOWS.md
- Tables for quick scanning
- Checklists for tracking
- Flowcharts for decision-making

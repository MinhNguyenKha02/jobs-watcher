## How to Use This Tracker

### For Each Question You Practice:

1. **Find the question** in the appropriate section below
2. **Mark attempt date** each time you practice it
3. **Score yourself** using the 5-block framework (1-5 score)
4. **Note gaps** - what was missing or weak
5. **Track improvements** - compare scores across attempts
6. **Mark complete** when you consistently score 5/5

### Scoring Guide

- **5/5** - All blocks present, clear, under time limit, handles edge cases
- **4/5** - All blocks present but minor clarity issues or slightly over time
- **3/5** - Missing 1 block or significant clarity issues
- **2/5** - Missing 2 blocks or major structural problems
- **1/5** - Unstructured or missing 3+ blocks

### Best Practice

- Practice each question at least 2-3 times
- Space attempts 2-3 days apart
- Review ideal answer from [interview-preparation.md](interview-preparation.md) between attempts
- Track in daily practice files (daily-YYYYMMDD.md)

## 💡 How to Use This Tracker Effectively

### Daily

1. **Before practice:** Pick next question from this tracker
2. **During practice:** Fill in daily-YYYYMMDD.md using [daily-compression-template.md](daily-compression-template.md)
3. **After practice:** Update this tracker with attempt details

### Weekly

1. **Sunday review:** Calculate statistics (questions attempted, average score)
2. **Identify patterns:** Which blocks are consistently weak?
3. **Plan next week:** Select questions based on gaps
4. **Update dashboard:** Fill in Progress Dashboard at top

### Monthly

1. **Trend analysis:** Compare week-over-week progress
2. **Gap closure:** Check if identified gaps from [gaps.md](gaps.md) are improving
3. **Difficulty progression:** Are you handling harder questions?
4. **Market readiness:** Do you have 5+ mastered questions for target market?

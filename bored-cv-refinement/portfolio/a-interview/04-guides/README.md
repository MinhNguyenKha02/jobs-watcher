## 🔥 Quick Reference: The Framework

### The 5 Blocks (Your Answer Structure)

```
1. VALIDATION   → Input validation & business rule checking
2. SERVICE      → Core business logic & orchestration  
3. PERSISTENCE → Data storage & transaction consistency
4. EXTERNAL     → Third-party API calls & integrations
5. FAILURE      → Error handling & recovery strategy
```

**Use this structure for ANY backend question.**

### Market Preferences (Emphasis)

| Market | Emphasis | Signal to Mention |
|--------|----------|---|
| **SG** | Transactions, clarity | "I'd use a transaction..." |
| **VN** | Practicality, APIs | "I'd implement retry with..." |
| **TH** | Database, state machines | "The schema would be..." |
| **MY** | Architecture, docs | "My project structure..." |
| **ID** | Speed, iteration | "I'd ship fast, then iterate..." |
| **EU** | CS fundamentals | "The complexity is O(n log n)..." |
| **US** | System thinking | "Here are the tradeoffs..." |

## 🆘 Troubleshooting

### "I'm stuck on Gap 1 (communication)"
**Problem:** Can't remember 5 blocks or keep mixing them up

**Solution:**
1. Write blocks on sticky notes (one per note)
2. Read each definition aloud 5x daily
3. Practice explaining each block to a friend
4. Record yourself saying blocks (replay daily)
5. Continue with daily compression template

**Timeline:** Usually clicks by Day 4-5

---

### "I'm jumping to advanced patterns"
**Problem:** Suggesting microservices, event sourcing for simple CRUD

**Solution:**
1. Read [interview-preparation.md - Q4 & Q5](interview-preparation.md#gap-2-over-abstraction) (see "Naive Junior Answer" vs "Strong Junior Answer")
2. Build CRUD-only APIs (no advanced patterns)
3. Add 3 edge cases instead of advanced architecture
4. When asked follow-up, then mention scaling

**Timeline:** Usually fixed by end of Week 2

---

### "My code takes too long"
**Problem:** Can't finish API in 45 minutes

**Solution:**
1. Practice smaller problems first (20 min)
2. Write pseudocode before code
3. Don't worry about perfection, worry about completion
4. Time yourself more often
5. Ask: What can I cut to ship in time?

**Timeline:** Time management improves by Week 2-3

---

### "I don't know if I'm improving"
**Problem:** Can't tell if daily practice is working

**Solution:**
1. Save all daily templates (days 1-7, then weeks 2-3, etc.)
2. Review Day 1 answer vs. Day 7 answer (same question)
3. Count blocks present: Day 1 (maybe 2-3) vs. Day 7 (should be 4-5)
4. Compare time: Day 1 (maybe 90s) vs. Day 7 (should be <60s)
5. You ARE improving; data proves it

**Timeline:** Clear improvement every 2-3 days

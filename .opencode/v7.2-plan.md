## 3-Consumer RabbitMqJobReader

### Interfaces & naming

```typescript
interface PendingJob {
  readonly id: string
  readonly job: JobData
  stage: 'PARTIAL' | 'FULL_PARSED'
}

interface S2BufferEntry {
  payload: JobData
  deliveryTag: number
  timestamp: number
}
```

### Properties

| Property | Type | Owner |
|---|---|---|
| `pendingJobs` | `PendingJob[]` | C1 push, C2 merge, C3 remove |
| `currentJobId` | `string \| null` | C1 set, C3 clear |
| `queueMode` | `boolean` | TUI mode |
| `deliveryTagsS1` | `Map<string, number[]>` | C1 store, C3 drain |
| `deliveryTagsS2` | `Map<string, number[]>` | C2 store, C3 drain |
| `deferredS2Buffer` | `Map<string, S2BufferEntry>` | C2 buffer, C1 drain |

### Methods

| Method | Visibility | Responsibility |
|---|---|---|
| `start()` | public | Consume all 3 queues |
| `stop()` | public | Cancel consumers, nack pending |
| `onMessageS1(msg)` | private | `job.generated` handler |
| `onMessageS2(msg)` | private | `job.parse.completed` handler |
| `onMessageS3S4(msg)` | private | S3/S4 handler |
| `ackAllForJob(id)` | private | Ack C1 + C2 delivery tags |
| `autoAdvance()` | private | Dequeue next pending job |
| `removeFromPending(id)` | private | Remove from pendingJobs array |
| `drainDeferredS2(id)` | private | Merge buffered S2 into pending entry |

### Consumer handlers

#### C1 — `tui.s1`, prefetch=5 — `onMessageS1(msg)`

```
store deliveryTag in deliveryTagsS1
if deferredS2Buffer has id:
  drainDeferredS2(id)         // merge S2 into job
  pendingJobs.push({id, mergedJob, stage: FULL_PARSED})
else:
  pendingJobs.push({id, job, stage: PARTIAL})
autoAdvance()
```

#### C2 — `tui.s2`, prefetch=5 — `onMessageS2(msg)`

```
store deliveryTag in deliveryTagsS2
if pendingJobs has id:
  merge job data into pending entry
elif id === currentJobId:
  setCurrentJob(id, mergedJob, FULL_PARSED)        // IPC write
elif queueMode === false:
  if currentJobId !== null:
    ackAllForJob(currentJobId)                     // ack orphaned previous tags
  setCurrentJob(id, job, FULL_PARSED)              // direct mode IPC write
  currentJobId = id
else:
  deferredS2Buffer.set(id, {payload, deliveryTag, timestamp})
  // max 10 entries, 30s TTL
```

#### C3 — `tui.s3s4`, prefetch=5 — `onMessageS3S4(msg)`

```
ackAllForJob(event.id)       // ack C1 + C2 tags
channel3.ack(msg)            // own ack (immediate)
removeFromPending(event.id)
if event.id === currentJobId:
  clearCurrentJob()
  currentJobId = null
if queueMode:
  autoAdvance()
// direct mode: stay idle, operator presses [i]
```

### Helpers

**ackAllForJob(id):**
```
for tag of (deliveryTagsS1.get(id) || []): channel1.ack(tag)
for tag of (deliveryTagsS2.get(id) || []): channel2.ack(tag)
deliveryTagsS1.delete(id)
deliveryTagsS2.delete(id)
```

**autoAdvance():**
```
if currentJobId !== null: return
if pendingJobs.length === 0: return
next = pendingJobs.shift()
currentJobId = next.id
setCurrentJob(next.id, next.job, next.stage)
```

**removeFromPending(id):**
```
idx = pendingJobs.findIndex(j => j.id === id)
if idx !== -1: pendingJobs.splice(idx, 1)
```

**DeferredS2Buffer TTL runner (setInterval 5s):**
```
for [id, entry] of deferredS2Buffer:
  if Date.now() - entry.timestamp > 30000:
    channel2.nack(entry.deliveryTag, false, false)  // discard, not requeue
    deferredS2Buffer.delete(id)
```

## Predictive Failures

| # | Failure | Behavior |
|---|---|---|
| F1 | Burst 10+ S1, C1 prefetch=5 | C1 backlogged, C2+C3 flow freely. No deadlock. |
| F2 | Operator presses [j] before S2 arrives | Ingestor guard rejects: status !== ENRICHED. No S3 published. Operator retries. |
| F3 | S2 arrives before S1 | DeferredS2Buffer holds (max 10, 30s TTL). C1 drains on S1 arrival. |
| F4 | Consumer crash mid-lifecycle | 3 channels reconnect. Unacked S1/S2 requeued. DeferredS2Buffer lost — TTL-safe (30s). |
| F5 | Direct mode rapid [i]×2 | C2 acks previous job's deliveryTags on overwrite. Zero leak. |
| F6 | S4 in direct mode | C3 ack + clearCurrentJob. No auto-advance. Operator presses [i] again. |
